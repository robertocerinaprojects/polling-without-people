# Legacy material

This folder contains historical code and documentation retained for review.
It is outside the active replication pipeline. Historical commands and paths
may no longer work after relocation.

See [the migration record](../docs/migration.md) for each file's status.

This folder is temporary and intended for eventual deletion. Before deletion,
resolve each outstanding replacement or retirement decision, preserve any
necessary methodological documentation outside this folder, and verify that
the active pipeline has no dependency on its contents.

Git history will retain tracked historical files after deletion.
Previously ignored reference files remain local-only; see the list in
[the migration record](../docs/migration.md).
